# 错误码清单

## 通用错误（1xxx）

| 错误码 | 常量 | HTTP | 含义 |
|--------|------|------|------|
| 1000 | `SERVER_ERROR` | 500 | 服务器内部错误 |
| 1001 | `VALIDATION_FAILED` | 422 | 请求参数校验失败 |
| 1002 | `NOT_FOUND` | 404 | 资源不存在 |
| 1003 | `METHOD_NOT_ALLOWED` | 405 | 请求方法不允许 |
| 1004 | `TOO_MANY_REQUESTS` | 429 | 请求过于频繁 |

## 认证与授权错误（2xxx）

| 错误码 | 常量 | HTTP | 含义 |
|--------|------|------|------|
| 2001 | `UNAUTHENTICATED` | 401 | 未提供认证凭证 |
| 2002 | `INVALID_TOKEN` | 401 | Token 无效或已过期 |
| 2003 | `WRONG_CREDENTIALS` | 401 | 账号或密码错误 |
| 2004 | `ACCOUNT_DISABLED` | 403 | 账号已被禁用 |
| 2005 | `FORBIDDEN` | 403 | 无权访问该资源 |

## 扩展规范

插件可注册自己的错误码段，避免与核心错误码冲突：

- 核心保留：`1000-1999`、`2000-2999`
- 插件市场：`5000-5999`
- 第三方插件：建议从 `10000` 开始，联系维护者申请段位
