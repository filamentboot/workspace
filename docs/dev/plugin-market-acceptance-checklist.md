# 插件市场基础包验收清单

## 后台入口

- `扩展清单` 可访问
- `官方市场` 可访问
- 两个入口都位于 `插件市场` 导航组

## 同步能力

- 能执行 `同步系统依赖`
- 能执行 `同步本地扩展`
- 能执行 `同步官方市场`
- 同步后能看到对应库存或市场缓存变化

## 扩展库存

- 能区分 `系统基础依赖`、`普通插件`、`方案型插件`
- 能看到来源、状态、版本、已安装版本
- 能查看详情页中的作者、摘要、说明、兼容性、安装结果、初始化结果

## 市场缓存

- 能搜索市场条目
- 能按类型、来源筛选
- 能看到本地状态对照
- 方案型插件详情页会显示更重的业务说明文案
- 非可信来源详情页只显示安装指引，不出现后台一键安装语义

## 安装与状态管理

- 官方可信来源可执行后台安装
- 普通插件安装后进入 `已安装`
- 方案型插件安装后进入 `待初始化`
- 非可信来源没有后台安装动作
- 普通插件支持启用、禁用
- 系统基础依赖不进入普通启停语义

## 初始化

- `待初始化` 状态可见
- 可从详情页执行初始化
- 初始化成功后能更新状态
- 初始化失败后能看到失败结果

## 审计与质量

- 安装、安装失败、启用、禁用会写入后台操作日志
- 已补充插件市场审计与权限说明文档
- `php artisan test tests/Feature/PluginPlatform tests/Unit/PluginPlatform` 通过
- `composer test` 通过
- `composer pint:test` 通过
- `composer phpstan` 通过
