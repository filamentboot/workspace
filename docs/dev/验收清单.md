# 一期验收清单

> 本文档供发布前人工核对使用。每个功能点标注验收方式：
> - **自动化**：对应 Pest 测试已覆盖，运行 `composer test` 即可验证
> - **手动**：需在浏览器中人工操作确认

## 环境准备

- [ ] MySQL 8.0（端口 3380）已启动
- [ ] Redis（端口 6379，密码 123456）已启动
- [ ] 已执行 `php artisan migrate --seed`（测试库：`php artisan migrate --env=testing`）
- [ ] Nginx 已配置 `filamentboot.local` 虚拟主机

---

## 1. 后台登录

| 验收项 | 方式 | 说明 |
|--------|------|------|
| 使用 username 登录 | 手动 | 访问 `http://filamentboot.local/admin`，输入用户名 `admin` + 密码 `password` |
| 使用 email 登录 | 手动 | 输入邮箱 `admin@example.com` + 密码 `password` |
| 错误密码提示 | 手动 | 输入错误密码，页面显示错误提示，不报 500 |
| 认证后跳转仪表盘 | 手动 | 登录成功后跳转至 `/admin` 仪表盘 |
| 登录链路端到端 | 自动 | `composer test -- --filter='执行核心 Seeder 后超级管理员可以登录后台'` |

## 2. 两步验证（2FA）

| 验收项 | 方式 | 说明 |
|--------|------|------|
| 可开启 2FA | 手动 | 进入个人资料页，开启 2FA，扫描二维码 |
| 2FA 验证码校验 | 手动 | 开启后重新登录，输入 TOTP 验证码 |
| 恢复码下载 | 手动 | 开启 2FA 时可下载恢复码文件 |

## 3. 登录日志

| 验收项 | 方式 | 说明 |
|--------|------|------|
| 登录事件写入日志 | 自动 | `composer test -- --filter='登录日志'` |
| 登录失败写入日志 | 自动 | 同上 |

## 4. 权限体系

| 验收项 | 方式 | 说明 |
|--------|------|------|
| super_admin 角色绕过所有权限检查 | 自动 | `composer test -- --filter='超级管理员绕过'` |
| 基础权限点已注册 | 自动 | `composer test -- --filter='执行核心 Seeder 后基础权限点已存在'` |
| Seed 后 super_admin 角色存在 | 自动 | `composer test -- --filter='super_admin 角色已在 admin guard 下创建'` |

## 5. 插件市场基础

| 验收项 | 方式 | 说明 |
|--------|------|------|
| 扩展列表可访问 | 自动 | `composer test -- --filter='扩展库存列表'` |
| 启用/禁用 Extension | 自动 | `composer test -- --filter='启用.*extension\|禁用.*extension'` |
| 禁用后导航消失 | 自动 | `composer test -- --filter='MarketEntryResource 导航'` |
| 市场同步不创建 Extension 记录 | 自动 | `composer test -- --filter='同步后 MarketEntry'` |
| 启停通知提示刷新页面 | 自动 | `composer test -- --filter='通知提示刷新页面'` |

## 6. 定时任务

| 验收项 | 方式 | 说明 |
|--------|------|------|
| 操作日志清理命令已调度 | 自动 | `composer test -- --filter='操作日志清理命令已注册每日'` |
| 登录日志清理命令已调度 | 自动 | `composer test -- --filter='登录日志清理命令已注册每日'` |
| 手动执行清理命令无报错 | 手动 | `php artisan filament-admin:clean-activity-logs --days=1` |

```bash
composer test
```
