# 插件市场基础包第一阶段

当前阶段已落地：

- 插件市场基础包骨架
- 系统基础依赖同步命令
- 本地已纳管插件同步命令
- 扩展清单后台列表页
- 扩展清单筛选与重同步入口
- 扩展详情页与文档入口信息展示
- 扩展详情页作者、摘要、说明与差异化管理提示
- 普通插件与方案型插件的基础启停动作、依赖提醒与操作日志接入
- 待初始化状态、详情页初始化入口与初始化执行记录
- 官方市场索引缓存、同步命令与同步入口
- 官方可信来源的基础安装动作、安装结果展示与恢复建议
- 官方市场列表、搜索、详情与本地状态对照
- 扩展 `registration` 声明协议与基础兼容性摘要

当前阶段未落地：

- 真实远程官方市场索引拉取
- 真实 Composer 安装执行链路
- 启停状态驱动菜单、页面、配置入口的真实运行时隐藏
- 普通插件与方案型插件的真实初始化执行链路与更细粒度进度展示
- 更完整的市场运营能力与真实发布分发流程
