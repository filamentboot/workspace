# 后台基础管理

后台基础管理是一组后台自管理能力，包含管理员管理、管理员日志、角色与权限、菜单规则、部门组织、数据权限和操作日志。

## 功能清单

- 管理员管理：创建、编辑、禁用、软删除、恢复、角色分配、部门归属，密码重置单独授权。
- 管理员日志：查看登录成功和失败记录，支持按管理员、账号、IP、状态、时间筛选。
- 角色与权限：继续使用 Filament Shield 自带角色管理，所有角色和权限固定使用 `admin` guard。
- 菜单规则：菜单数据接管后台左侧导航，支持权限绑定、启停控制和排序。
- 部门组织：维护部门树、负责人和管理员主部门。
- 数据权限：按角色配置全部数据、本部门、本部门及下级、仅本人、指定部门。
- 操作日志：记录后台关键操作，并支持按保留天数清理旧日志。

## 当前实现口径

- 一期资源已包含：管理员管理、管理员日志、菜单规则、部门管理、数据权限、操作日志访问。
- 角色管理继续复用 Shield 自带 `RoleResource`，不在项目里重复手写。
- 动态导航已接入 `menus` 表，但菜单初始内容依赖 `AdminFoundationMenuSeeder`。
- 数据权限当前已接入管理员列表和登录日志列表。
- 操作日志页面复用 `alizharb/filament-activity-log`，项目内补充统一写日志服务、模型观察器和清理命令。
- 关键后台动作已接入操作日志，包括管理员资料变更、密码重置、角色变更、菜单排序、部门变更、数据权限配置变更。

## 开发约定

- 后台管理员使用 `admin` guard 和 `admin_users` 表。
- 角色和权限必须使用 `guard_name = admin`。
- 菜单只控制导航展示，不替代 Filament Resource 路由注册。
- 数据权限当前只做角色级范围，不做字段级权限。
