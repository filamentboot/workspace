## 1. 执行摘要

完善系统管理能力,包含媒体库(文件上传、预览、管理)、基础导出(表格导出、权限控制)、系统配置(站点配置、上传配置、安全配置、日志配置),为后续业务模块提供完整的系统管理基础。

---

## 2. 问题陈述

### 2.1 谁有这个问题?

FilamentAdmin 用户需要上传和管理文件(头像、Logo、附件),需要导出数据,需要统一配置管理系统。

### 2.2 问题是什么?

- 没有统一的文件上传和管理入口
- 没有数据导出能力
- 系统配置分散在代码或环境变量中
- 插件配置没有统一入口

### 2.3 为什么痛苦?

- 每个功能模块自己实现上传,代码重复
- 用户需要手动复制数据或写脚本导出
- 修改配置需要开发者介入,运维成本高

---

## 3. 目标用户

### 主要角色:内容编辑和系统管理员

- 内容编辑:负责后台内容管理,需要上传和管理文件
- 系统管理员:负责系统运维,需要修改系统配置

**Jobs-to-be-Done**:
> "当需要上传文件时,我想要统一的媒体库,这样可以上传、预览、管理文件。"
> "当需要导出数据时,我想要安全的导出功能,这样可以导出指定字段的数据。"
> "当需要修改系统配置时,我想要统一的配置管理页面,这样我可以快速修改配置。"

---

## 4. 解决方案概述

### 4.1 核心能力

| 能力域 | 描述 | 技术实现 |
|--------|------|---------|
| 媒体库 | 文件上传、预览、管理、Collection 规范 | spatie/laravel-medialibrary + Filament 插件 |
| 基础导出 | 表格导出、权限控制、字段白名单、审计记录 | maatwebsite/excel 或 Filament 导出插件 |
| 系统配置 | 站点配置、上传配置、安全配置、日志配置、插件配置入口 | spatie/laravel-settings + Filament 配置页 |

### 4.2 关键用户流程

#### 流程 1:上传文件

```
1. 进入后台 → 媒体库 → 上传文件
2. 选择文件或拖拽上传
3. 系统校验文件大小、类型
4. 上传成功,显示预览
5. 文件出现在媒体库列表
```

#### 流程 2:导出数据

```
1. 进入后台 → 管理员列表
2. 点击"导出"按钮
3. 选择导出格式(Excel/CSV)
4. 系统导出当前筛选条件的数据
5. 浏览器下载导出文件
```

#### 流程 3:修改系统配置

```
1. 进入后台 → 系统配置 → 基础配置
2. 修改站点名称、后台标题、上传 Logo
3. 保存配置
4. 配置缓存失效,新配置立即生效
```

## 5. 功能需求

### 5.1 媒体库

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| MediaLibrary 接入 | spatie/laravel-medialibrary + Filament 插件 | composer require 安装 |
| 媒体管理页面 | 文件列表、预览、下载、删除、筛选 | Filament Resource |
| Collection 规范 | avatar、logo、attachments、content_images | MediaLibrary Collections |
| 上传安全 | 文件大小、MIME、扩展名、危险文件拦截 | 白名单校验 |
| 实际场景接入 | 管理员头像、系统 Logo 使用媒体库 | 真实功能使用 |

### 5.2 基础导出

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 表格导出 | 常用 Resource 列表导出(Excel/CSV) | maatwebsite/excel 或 Filament 导出插件 |
| 权限控制 | 导出需要单独权限点,不等同于 viewAny | Shield 权限配置 |
| 字段白名单 | 敏感字段默认不导出(密码、token 等) | 配置化白名单 |
| 大数据处理 | 当前先支持同步导出,预留队列导出 | 小数据量直接导出 |
| 审计记录 | 导出行为进入操作日志 | spatie/laravel-activitylog |

### 5.3 系统配置

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 基础配置 | 站点名称、后台标题、Logo、备案信息、联系方式 | spatie/laravel-settings |
| 上传配置 | 文件大小、允许类型、默认磁盘、图片尺寸策略 | spatie/laravel-settings |
| 安全配置 | 登录限制、2FA 提示、账号安全开关 | spatie/laravel-settings |
| 日志配置 | 登录日志和操作日志保留天数、清理命令 | spatie/laravel-settings + Schedule |
| 插件配置入口 | 插件声明 Settings 类,出现在配置中心 | 插件注册机制 |
| 配置缓存 | 配置变更后缓存失效 | Laravel Cache |
