## 1. 执行摘要

提供插件市场能力,作为独立 Composer 基础包(`filament-admin/plugin-platform`)依赖 Filamentboot,实现插件浏览、安装、启停、初始化、远程索引、版本兼容性矩阵等核心能力。

---

## 2. 第一阶段：基础能力 (v0.5.0-beta.1)

### 2.1 问题陈述

Filamentboot 用户需要扩展系统功能,但手动集成第三方扩展包需要修改代码、配置 Service Provider、发布资源等,操作繁琐。

### 2.2 核心能力

| 能力域 | 描述 | 技术实现 |
|--------|------|---------|
| 插件市场架构 | 独立 Composer 基础包 | packages/plugin-platform/ |
| 插件列表 | 查看已安装插件和状态 | 本地数据库 + Composer 扫描 |
| 插件启停 | 启用/禁用插件 | 真实注册/注销 Service Provider |
| 插件初始化 | 迁移、发布资源、种子数据 | Artisan 命令 + 向导 |
| 插件配置 | Settings 类 + 配置页 | spatie/laravel-settings |
| 依赖冲突检测 | 检测插件间依赖冲突 | 依赖解析器 |
| 插件卸载清理 | 卸载时清理残留数据 | 清理脚本 + 数据表 |

### 2.3 关键用户流程

#### 启用插件

```
1. 插件列表页点击"启用"按钮
2. 系统检测依赖冲突(如有冲突则阻断)
3. 系统注册插件的导航、Resource、Page、配置入口
4. 插件状态变为"已启用"
5. 后台导航出现新菜单项
```

#### 卸载插件

```
1. 插件列表页点击"卸载"按钮
2. 系统提示:卸载将删除插件数据(可勾选保留)
3. 执行清理:删除插件数据表、配置、资源
4. 插件状态变为"已卸载"
```

#### 插件市场架构

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 独立包 | 独立 Composer 基础包 | composer.json 声明依赖 Filamentboot |
| 命名空间 | 独立命名空间 | PluginPlatform\ |
| Service Provider | 插件市场服务提供者 | 注册到 Laravel |
| Migration | 插件市场数据表 | plugins、plugin_install_logs 等 |
| Filament Plugin | 注册到后台 Panel | 通过 Plugin 接口接入 |

#### 插件列表与状态

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 列表页 | 显示已安装插件 | 名称、版本、状态、描述 |
| 状态筛选 | 按状态过滤 | 已启用/已禁用/待初始化/已卸载 |
| 状态来源 | 本地数据库 | 已安装插件表 |
| Composer 扫描 | 识别已安装扩展包 | 读取 composer.json 元数据 |

#### 插件启停

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 启用按钮 | 禁用状态的插件可启用 | 点击后注册能力 |
| 禁用按钮 | 启用状态的插件可禁用 | 点击后隐藏能力 |
| 注册能力 | 导航、Resource、Page、配置 | 真实影响后台 |
| 依赖检测 | 禁用被依赖插件时提示 | 阻断或明确风险提示 |

#### 插件初始化

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 待初始化状态 | 新安装插件进入此状态 | 状态流转 |
| 初始化向导 | 引导用户完成初始化 | Migration、发布资源、种子数据 |
| 失败重试 | 初始化失败可重试 | 保留日志、重试入口 |
| 完成状态 | 初始化完成后变为已启用 | 状态更新 |

#### 插件配置

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| Settings 类 | 插件声明配置项 | 强类型 PHP Settings 类 |
| 配置页 | 自动生成配置页面 | Filament 配置页 |
| 配置缓存 | 配置结果可缓存 | 提升性能 |

#### 插件依赖冲突检测 ⚠️ 高复杂度

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 依赖声明 | 插件声明依赖的其他插件 | composer.json 或元数据 |
| 冲突检测 | 启用插件时检测依赖是否满足 | 不满足则阻断并提示 |
| 版本兼容 | 检测插件与 Filamentboot 版本兼容 | 不兼容则阻断 |
| 循环依赖检测 | 检测 A→B→A 循环依赖 | 阻断并提示 |

**技术难点**:
- 需要实现依赖解析器,类似 Composer 的依赖解析逻辑
- 循环依赖检测需要图算法(DFS/BFS)
- 版本兼容性需要语义化版本比较(SemVer)

**缓解方案**:
- 先做简单依赖检测(只检查是否安装)
- 再做版本兼容性和循环依赖检测

#### 插件卸载清理 ⚠️ 高复杂度

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 数据表清理 | 卸载时删除插件数据表 | Migration rollback |
| 配置清理 | 删除插件配置 | Settings 表清理 |
| 资源清理 | 删除插件发布的资源 | public/vendor/ 目录清理 |
| 菜单清理 | 删除插件注册的菜单 | menus 表清理 |
| 权限清理 | 删除插件注册的权限 | permissions 表清理 |
| 可选保留 | 用户可选择保留部分数据 | 勾选框 |

**技术难点**:
- Migration rollback 可能失败(如果用户已修改表结构)
- 资源清理需要记录插件发布了哪些文件

**缓解方案**:
- 插件必须声明清理脚本(类似 Laravel Package 的 teardown)
- 提供"软卸载"选项(只禁用,不删除数据)

#### 插件 Service Provider 动态注册/注销 ⚠️ 极高复杂度

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 动态注册 | 启用插件时注册 Service Provider | 插件能力立即可用 |
| 动态注销 | 禁用插件时注销 Service Provider | 插件能力立即隐藏 |
| 路由注册 | 插件路由动态注册 | 路由不冲突 |
| 路由注销 | 插件路由动态注销 | 路由不可访问 |

**技术难点**:
- Laravel Service Provider 通常在启动时注册,运行时动态注册/注销非常困难
- 路由注册后无法动态注销(需要清缓存 + 重启)

**缓解方案**:
- 启停操作后提示"需要清缓存或重启"
- 使用配置缓存 + 路由缓存控制可见性
- 不真正注销 Service Provider,而是通过配置开关控制能力

## 3. 第二阶段：远程索引 (v0.5.0-beta.2)

### 3.1 问题陈述

Filamentboot 用户需要发现和安装官方提供的插件,但当前只能查看本地已安装插件,无法浏览远程市场。

### 3.2 核心能力

| 能力域 | 描述 | 技术实现 |
|--------|------|---------|
| 远程索引读取 | 浏览官方插件市场 | JSON 索引 + HTTP 缓存 |
| 插件详情 | 查看插件功能和说明 | 远程读取,不长期写 MySQL |
| 安装入口 | 官方可信来源可安装 | 仅官方可信来源显示安装按钮 |
| 安装进度 | 查看安装进度和日志 | 队列任务 + Livewire |
| 版本兼容性矩阵 | 插件与 Filamentboot 版本兼容关系 | 兼容性元数据 |
| 插件依赖解析 | 自动解析插件依赖 | 依赖解析器 |

### 3.3 关键用户流程

#### 浏览官方市场

```
1. 进入后台 → 插件中心 → 浏览官方市场
2. 从远程 JSON 索引读取插件列表
3. 显示插件名称、分类、版本、作者、说明、来源标签
4. 优先从远程读取,不长期写入本地 MySQL
5. 显示与当前 Filamentboot 版本的兼容性
```

#### 安装插件

```
1. 点击"安装"按钮
2. 系统检测依赖是否满足(如不满足则阻断)
3. 系统检测版本兼容性(如不兼容则阻断)
4. 安装任务推送到队列
5. 后台显示安装进度(Livewire 推送)
6. 安装完成后提示"启用插件"和"初始化插件"
```

### 3.4 功能需求

#### 远程索引读取

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| JSON 索引 | 从远程读取插件索引 | HTTP GET 远程 JSON URL |
| 插件列表 | 显示插件基本信息 | 名称、分类、版本、作者、说明 |
| 来源标签 | 区分插件来源 | 官方可信/官方收录/开源生态 |
| 缓存策略 | 不长期写 MySQL | HTTP 缓存或短期应用缓存 |
| 兼容性显示 | 显示与当前版本兼容性 | 兼容/不兼容/未知 |

#### 插件详情与安装

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 详情页 | 显示插件完整信息 | 功能说明、截图、依赖、安装命令、文档 |
| 安装按钮 | 仅官方可信来源可安装 | 其他来源显示安装指引 |
| 兼容性检查 | 检查与当前版本兼容性 | 不兼容时提示并阻断 |
| 依赖检查 | 检查插件依赖是否满足 | 不满足时提示并阻断 |
| 依赖自动安装 | 可选自动安装依赖插件 | 用户确认 |

#### 安装进度与日志

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 队列任务 | 安装任务推送到队列 | 异步执行 |
| 进度推送 | Livewire 实时推送进度 | 显示安装步骤 |
| 安装日志 | 记录安装过程 | 执行步骤、成功/失败 |
| 失败重试 | 安装失败可重试 | 保留日志、重试入口 |

#### 版本兼容性矩阵 ⚠️ 高复杂度

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 兼容性元数据 | 插件声明兼容的 Filamentboot 版本 | 如 "^0.1.0 \|\| ^0.2.0" |
| 版本比较 | 语义化版本比较(SemVer) | 正确判断兼容性 |
| 兼容性提示 | 不兼容时明确提示 | "此插件兼容 Filamentboot v0.2.0+,当前 v0.1.0" |
| 兼容性缓存 | 兼容性结果缓存 | 避免重复计算 |

**技术难点**:
- 需要实现语义化版本比较器(SemVer)
- 兼容性表达式解析(如 "^0.1.0 \|\| ^0.2.0")

**缓解方案**:
- 使用现有 SemVer 库(如 `composer/semver`)
- 兼容性表达式遵循 Composer 格式

#### 插件依赖解析 ⚠️ 高复杂度

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 依赖声明 | 插件声明依赖的其他插件及版本 | 元数据声明 |
| 依赖解析 | 安装时解析完整依赖树 | 递归解析 |
| 依赖安装 | 可选自动安装依赖插件 | 用户确认 |
| 循环依赖检测 | 检测 A→B→A 循环依赖 | 阻断并提示 |
| 依赖冲突 | 检测依赖版本冲突 | 阻断并提示 |

**技术难点**:
- 递归依赖解析可能很深
- 循环依赖需要图算法检测
- 版本冲突需要类似 Composer 的依赖解析器

**缓解方案**:
- 限制依赖深度(最多 2 层)
- 使用 DFS 检测循环依赖
- 版本冲突复用第一阶段依赖解析器

#### 数据边界控制 ⚠️ 架构约束

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 浏览数据不落 MySQL | 远程索引数据不长期存储 | 只使用 HTTP 缓存 |
| 已安装数据落 MySQL | 安装后才写入本地 | plugins 表 |
| 缓存过期策略 | HTTP 缓存有明确过期时间 | 如 24 小时 |
| 手动刷新 | 用户可手动刷新市场数据 | 刷新按钮 |

**架构约束**:
- 这是插件市场的核心架构决策,必须严格遵守
- 未安装插件的浏览数据(名称、说明、截图等)不写入本地 MySQL
- 只有用户实际安装的插件才写入本地 plugins 表

### 3.5 成功指标

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 远程索引加载成功率 | > 95% | 加载成功/总加载次数 |
| 插件安装成功率 | > 90% | 安装成功/总安装次数 |
| 兼容性检测准确率 | > 99% | 检测准确/总检测次数 |
| 依赖解析准确率 | > 95% | 解析准确/总解析次数 |

### 3.6 依赖与风险

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| 远程索引不可用 | 无法浏览市场 | 中 | 缓存策略,降级提示 |
| 安装失败无法恢复 | 系统处于不一致状态 | 中 | 保留日志、重试入口 |
| 数据模型设计错误 | 未安装插件数据污染本地 MySQL | 中 | 严格区分浏览数据和已安装数据,代码审查 |
| 兼容性检测错误 | 安装了不兼容插件 | 低 | 严格 SemVer 比较,测试覆盖 |
| 依赖解析死循环 | 循环依赖导致系统卡死 | 低 | 限制依赖深度,循环检测 |
