## 1. 执行摘要

提供管理员认证、角色权限、菜单管理、登录日志、操作日志、部门管理、个人资料页、后台首页等核心能力。

---

## 2. 解决方案概述

### 2.1 核心能力

| 能力域 | 描述 | 技术实现 |
|--------|------|---------|
| 管理员登录 | username/email 登录 | Filament 5 自定义登录页 |
| 双因素认证 | TOTP + Recovery Code | stephenjude/filament-two-factor-authentication |
| 管理员管理 | 创建、编辑、禁用、软删除 | AdminUser 模型 + Filament Resource |
| 角色权限 | Spatie Permission + Shield | spatie/laravel-permission + bezhansalleh/filament-shield |
| 菜单管理 | 树形菜单、权限绑定 | 自定义 Menu 模型 + Resource |
| 登录日志 | 登录行为记录 | 自定义 Listener + 数据表 |
| 操作日志 | 操作审计追踪 | spatie/laravel-activitylog |
| 部门管理 | 部门树、管理员绑定 | Department 模型 + Resource |
| 个人资料页 | 修改密码、头像、启用 2FA、查看登录日志 | Filament Profile Page |
| 后台首页 | 欢迎卡片、常用功能入口、最近操作记录、系统状态概览、快速引导 | Filament Widgets |

### 2.2 关键用户流程

#### 流程 1:管理员登录

```
1. 访问 http://localhost/admin
2. 输入用户名或邮箱 + 密码
3. 若启用 2FA,输入验证码
4. 登录成功跳转到后台首页
5. 记录登录日志(IP、UA、时间)
```

#### 流程 2:配置角色权限

```
1. 进入后台 → 角色管理 → 创建新角色
2. 勾选允许的菜单和资源操作
3. 配置数据权限范围(本部门/本人/全部)
4. 将角色分配给管理员
```

## 3. 功能需求

### 3.1 管理员登录

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 登录方式 | 支持 username 或 email | 登录页可输入用户名或邮箱 |
| 登录限流 | 每分钟最多 5 次尝试 | 超限后锁定账户 |
| 错误提示 | 不区分用户名/密码错误 | 显示"账号或密码错误" |
| 登录日志 | 记录登录行为 | IP、UA、时间、成功/失败 |

### 3.2 双因素认证

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 启用/关闭 | 个人设置页操作 | 启用时显示 QR Code 和恢复码 |
| TOTP 验证 | 登录后输入验证码 | 支持 Google Authenticator 等应用 |
| 恢复码登录 | 使用恢复码登录 | 一次性使用,使用后失效 |

### 3.3 管理员管理

**简化方案**: 对比 FastAdmin 实现,当前设计过于复杂,简化如下:

| 维度 | 当前实现 | 简化方案 |
|------|---------|-------------|
| 页面结构 | 4 个独立页面(List/Create/Edit/View) | 删除 ViewAdminUser,保留 List/Create/Edit |
| 字段命名 | username(用户名)、name(姓名) | account(账号)、nickname(昵称) |
| 新增字段 | ❌ 缺失 | avatar(头像)、mobile(手机号)、last_login_at(最后登录时间)、last_login_ip(最后登录IP)、login_failures(登录失败次数) |
| 数据权限 | DataScopeResolver 150 行复杂逻辑 | 超管看全部,普通人看自己 |
| 数据权限配置 | RoleDataScopeResource 独立页面 | 删除,后续版本再加 |

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 列表页 | 搜索、筛选、分页 | 支持按账号、昵称、邮箱、角色筛选 |
| 创建管理员 | 账号、昵称、邮箱、手机号、密码、角色 | 密码强度校验 |
| 编辑管理员 | 修改资料、重置密码、启用/禁用 | 权限控制 |
| 软删除 | 删除进入回收站 | 可恢复、可彻底删除 |
| 头像 | 管理员头像上传 | 简单上传,后续接入媒体库 |
| 登录信息 | 显示最后登录时间、IP、失败次数 | 列表页展示 |
| 按钮权限 | 批量删除、重置密码、分配角色 | 每个按钮都有权限点控制 |

**删除文件清单**:
- `app/Filament/Resources/AdminUsers/Pages/ViewAdminUser.php`
- `app/Filament/Resources/RoleDataScopes/RoleDataScopeResource.php`
- `app/Filament/Resources/RoleDataScopes/Pages/*.php`
- `app/Services/DataScopeResolver.php`
- `app/Enums/DataScope.php`
- `app/Models/RoleDataScope.php`
- 相关迁移文件

**简化后的数据权限逻辑**:
```php
// AdminUserResource::getEloquentQuery()
public static function getEloquentQuery(): Builder
{
    $query = parent::getEloquentQuery();
    
    // 超级管理员看全部
    if (auth('admin')->user()->hasRole(config('filament-admin.super_admin_role'))) {
        return $query;
    }
    
    // 普通管理员只看自己
    return $query->where('id', auth('admin')->id());
}
```

### 3.4 角色权限

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 角色创建 | 名称、描述、权限勾选 | 权限点自动生成自 Shield |
| 权限分配 | 菜单权限、操作权限 | 勾选后生效 |
| 超级管理员 | Gate::before() 绕过 | 不受权限检查限制 |
| 角色分配 | 管理员可分配多角色 | 权限合并 |

### 3.5 菜单管理

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 菜单列表 | 树形展示、拖拽排序 | 支持无限级 |
| 创建菜单 | 名称、图标、路由、父菜单、权限 | 表单验证 |
| 权限绑定 | 菜单可见性根据角色过滤 | 无权限不显示 |
| 插件菜单 | 插件可注册自己的菜单 | 通过 Filament Plugin 接入 |

### 3.6 登录日志

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 自动记录 | Event Listener 触发 | 登录成功/失败都记录 |
| 列表页 | 管理员、IP、UA、时间 | 支持筛选 |
| 只读 | 不支持删除 | 审计要求 |

### 3.7 操作日志

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 自动记录 | spatie/laravel-activitylog | 记录 Model 变更 diff |
| 列表页 | 操作人、对象、类型、时间 | 支持筛选 |
| 覆盖范围 | 核心后台动作 | 管理员、角色、菜单、部门 |
| 只读 | 不支持删除 | 审计要求 |

### 3.8 部门管理

**简化方案**: 保留部门树管理,删除数据权限配置(后续版本再加)

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 部门管理 | 创建、编辑、删除部门 | 树形结构,支持拖拽排序 |
| 管理员绑定 | 管理员绑定所属部门 | 单部门绑定 |
| 部门负责人 | 部门可设置负责人 | 关联管理员 |
| 部门编码 | 唯一编码 | 必填,唯一校验 |
| 启用/禁用 | 部门可停用 | 停用后管理员不可绑定 |

**不做**:
- 数据权限配置(RoleDataScopeResource) → 后续版本再加
- 多部门绑定 → 单部门
- 复杂数据权限过滤 → 超管看全部,普通人看自己

### 3.9 个人资料页

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 基本信息 | 查看和修改账号、昵称、邮箱、头像 | 简单上传头像 |
| 修改密码 | 当前密码 + 新密码 + 确认新密码 | 验证当前密码正确 |
| 双因素认证 | 启用/关闭 2FA,查看恢复码 | QR Code 扫描,恢复码显示 |
| 登录日志 | 查看自己的登录日志 | 最近 10 条 |
| 退出登录 | 退出当前会话 | 跳转到登录页 |

### 3.10 后台首页

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 欢迎卡片 | 项目名称、版本号、快速开始引导 | "欢迎使用 Filamentboot,点击开始配置" |
| 常用功能入口 | 管理员管理、角色权限、菜单管理、系统配置 | 图标 + 文字,按使用频率排序 |
| 最近操作记录 | 最近 5-10 条操作日志 | 操作人、对象、动作、时间 |
| 系统状态概览 | 管理员数、角色数、今日登录数 | 简化版,不显示技术版本信息 |
| 快速引导 | 新用户引导步骤(创建角色→创建管理员→配置菜单) | 可关闭,步骤清晰 |

**设计原则**: 后台首页面向业务管理员,不是开发者。避免显示 PHP/Laravel 版本等技术信息,聚焦"我能做什么"和"系统当前状态"。

## 6. 依赖与风险

| 风险 | 影响 | 概率 | 缓解措施 |
