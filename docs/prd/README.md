## 架构决策记录

| 决策 | 内容 | 影响文档 |
|------|------|---------|
| 插件市场数据边界 | 未安装市场条目不长期写入本地 MySQL,只使用 HTTP 缓存 | 06-插件市场.md |
| 插件启停机制 | 启停后需要清缓存,不真正动态注销 Service Provider | 06-插件市场.md |
| Skeleton 包定位 | 宿主提供基础能力 + 扩展点,用户通过继承扩展,不直接改宿主代码 | 全量 |
| 测试策略 | 测试金字塔:Unit 20% → Feature 50% → Integration 25% → E2E 5% | 全量 |
