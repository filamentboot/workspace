# 系统配置 实现计划

> 修订记录：2026-05-29 根据代码审查问题清单修复 8 项问题。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现基于 Spatie Laravel Settings 的系统配置管理，包含 GeneralSettings 配置类、Filament 配置页面、Redis 缓存机制、SettingsUpdated 事件和插件配置注册接口。

**Architecture:** 使用 spatie/laravel-settings 将配置存储在数据库，通过 filament/spatie-laravel-settings-plugin 自动生成 Filament 配置页面。配置读取时使用 Redis 缓存，保存时清除缓存。提供 SettingsRegistry 供插件注册自己的配置类。

**Tech Stack:** spatie/laravel-settings ^3.0, filament/spatie-laravel-settings-plugin ^5.0, Pest

- [ ] **Step 1: 创建 `app/Settings/` 目录并新建 GeneralSettings.php**

```php
<?php

namespace App\Settings;

use Spatie\LaravelSettings\Settings;

/**
 * 通用系统配置
 *
 * 存储站点基本信息，包括站点名称、Logo、备案号、联系邮箱和日志保留天数。
 * 数据保存在 settings 表的 general group 下。
 */
class GeneralSettings extends Settings
{
    /** 站点名称 */
    public string $site_name = 'FilamentAdmin';

    /** 站点 Logo 路径（相对于 public 目录） */
    public string $site_logo = '';

    /** ICP 备案号 */
    public string $icp_number = '';

    /** 联系邮箱 */
    public string $contact_email = '';

    /** 日志保留天数 */
    public int $log_retention_days = 90;

    /**
     * 配置分组名称
     */
    public static function group(): string
    {
        return 'general';
    }
}
```

<?php

namespace App\Filament\Pages;

use App\Settings\GeneralSettings;
use Filament\Schemas\Components\Section;
use Filament\Forms\Components\TextInput;
use Filament\Schemas\Schema;
use Filament\Pages\SettingsPage;

/**
 * 通用系统配置管理页面
 *
 * 提供站点名称、Logo、备案号、联系邮箱和日志保留天数的配置界面。
 */
class ManageGeneralSettings extends SettingsPage
{
    /** 页面标题 */
    protected static ?string $title = '系统配置';

    /** 导航图标 */
    protected static ?string $navigationIcon = 'heroicon-o-cog-6-tooth';

    /** 导航分组 */
    protected static ?string $navigationGroup = '系统管理';

    /** 导航排序 */
    protected static ?int $navigationSort = 100;

    /** 对应的 Settings 类 */
    protected static string $settings = GeneralSettings::class;

    /**
     * 定义表单 Schema
     *
     * Filament 5 表单 API：使用 `Filament\Schemas\Schema` + `->components([...])`，
     * 不再使用 Filament 3.x 的 `Forms\Form` + `->schema([...])`。
     */
    public function form(Schema $schema): Schema
    {
        return $schema
            ->components([
                Section::make('基本信息')
                    ->description('配置站点的基本展示信息')
                    ->components([
                        TextInput::make('site_name')
                            ->label('站点名称')
                            ->required()
                            ->maxLength(100),

                        TextInput::make('site_logo')
                            ->label('站点 Logo 路径')
                            ->placeholder('例如：/images/logo.png')
                            ->maxLength(255),

                        TextInput::make('icp_number')
                            ->label('ICP 备案号')
                            ->placeholder('例如：京ICP备12345678号')
                            ->maxLength(100),

                        TextInput::make('contact_email')
                            ->label('联系邮箱')
                            ->email()
                            ->maxLength(255),
                    ]),

                Section::make('日志设置')
                    ->components([
                        TextInput::make('log_retention_days')
                            ->label('日志保留天数')
                            ->required()
                            ->integer()
                            ->minValue(1)
                            ->maxValue(3650)
                            ->suffix('天'),
                    ]),
            ]);
    }
}

<?php

namespace App\Services;

/**
 * Settings 类注册表
 *
 * 提供统一的接口供应用和插件注册自己的 Settings 类。
 * 注册后的类可被框架层统一管理，例如在迁移、缓存清除时遍历所有配置类。
 */
class SettingsRegistry
{
    /** @var array<int, class-string<\Spatie\LaravelSettings\Settings>> 已注册的 Settings 类列表 */
    private static array $settings = [];

    /**
     * 注册一个 Settings 类
     *
     * @param class-string<\Spatie\LaravelSettings\Settings> $settingsClass Settings 类的完全限定类名
     */
    public static function register(string $settingsClass): void
    {
        if (! in_array($settingsClass, static::$settings, true)) {
            static::$settings[] = $settingsClass;
        }
    }

    /**
     * 获取所有已注册的 Settings 类
     *
     * @return array<int, class-string<\Spatie\LaravelSettings\Settings>>
     */
    public static function all(): array
    {
        return static::$settings;
    }

    /**
     * 重置注册表（主要用于测试）
     */
    public static function reset(): void
    {
        static::$settings = [];
    }
}

# 系统配置功能

## 概述

本模块基于 [spatie/laravel-settings](https://github.com/spatie/laravel-settings) 实现类型安全的系统配置管理，并通过 [filament/spatie-laravel-settings-plugin](https://github.com/filament/spatie-laravel-settings-plugin) 自动生成 Filament 后台配置页面。

## 架构

```
┌─────────────────────────────────────────────────┐
│              ManageGeneralSettings               │
│         (Filament 配置管理页面)                   │
│  ┌─────────────────────────────────────────────┐ │
│  │  site_name / site_logo / icp_number          │ │
│  │  contact_email / log_retention_days          │ │
│  └─────────────────────────────────────────────┘ │
│                     ↓ save()                     │
│            SettingsUpdated::dispatch()           │
└─────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────┐
│              GeneralSettings                     │
│  (spatie/laravel-settings Settings 类)           │
│  - group: 'general'                              │
│  - 持久化到 settings 表                          │
│  - 通过 Redis 缓存加速读取                        │
└─────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────┐
│               SettingsRegistry                   │
│  - 供插件注册自己的 Settings 类                   │
│  - AppServiceProvider 启动时注册 GeneralSettings  │
└─────────────────────────────────────────────────┘
```

## 配置项说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `site_name` | string | `FilamentAdmin` | 站点名称，显示在页面标题 |
| `site_logo` | string | `''` | 站点 Logo 路径（相对 public 目录） |
| `icp_number` | string | `''` | ICP 备案号，显示在页脚 |
| `contact_email` | string | `''` | 联系邮箱 |
| `log_retention_days` | int | `90` | 日志保留天数（1~3650） |

## 使用方式

### 读取配置

```php
$settings = app(\App\Settings\GeneralSettings::class);
echo $settings->site_name; // 'FilamentAdmin'
```

### 修改配置（代码层面）

```php
$settings = app(\App\Settings\GeneralSettings::class);
$settings->site_name = '新站点名称';
$settings->save();
```

### 监听配置变更事件

```php
use App\Events\SettingsUpdated;

Event::listen(SettingsUpdated::class, function (SettingsUpdated $event) {
    // $event->settingsClass 为 GeneralSettings::class
    Cache::flush(); // 示例：清除应用缓存
});
```

### 插件注册自定义配置

```php
// 在插件的 ServiceProvider::boot() 中
use App\Services\SettingsRegistry;
use MyPlugin\Settings\MyPluginSettings;

SettingsRegistry::register(MyPluginSettings::class);
```

## 缓存

配置读取时通过 Redis 缓存加速，每次调用 `$settings->save()` 后缓存自动失效并重建。

相关环境变量：

```
SETTINGS_CACHE_ENABLED=true
SETTINGS_CACHE_STORE=redis
```

## 数据库

配置存储在 `settings` 表，结构：

| 列 | 类型 | 说明 |
|----|------|------|
| `group` | varchar | 配置分组（如 `general`） |
| `name` | varchar | 配置项名称（如 `site_name`） |
| `payload` | longtext | JSON 序列化的值 |
| `locked` | tinyint | 是否锁定（不允许通过代码修改） |
```
