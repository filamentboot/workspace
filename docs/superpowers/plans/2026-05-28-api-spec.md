# API 规范 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现统一的 API 响应规范，包含 Sanctum Token 认证、统一 JSON 响应格式、BusinessException 异常类和 ErrorCodeRegistry 错误码注册机制。

**Architecture:** 所有 API 响应通过 Handler.php 统一格式化。BusinessException 携带错误码，Handler 捕获后输出标准格式。ErrorCodeRegistry 单例管理全局错误码，支持插件注册自己的错误码段。

**Tech Stack:** laravel/sanctum (内置), Pest

use App\Exceptions\BusinessException;
use App\Services\ErrorCodeRegistry;
use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;

use Illuminate\Http\Request;
use Illuminate\Validation\ValidationException;

        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
        then: function (): void {
            // 注册 admin-api 路由，前缀 /admin/api
            \Illuminate\Support\Facades\Route::middleware('web')
                ->prefix('admin/api')
                ->group(base_path('routes/admin-api.php'));
        },
    )
    ->withMiddleware(function (Middleware $middleware): void {
        //
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        // 对所有 /api/* 和 /admin/api/* 请求返回 JSON
        $exceptions->shouldRenderJsonWhen(
            fn (Request $request) => $request->is('api/*') || $request->is('admin/api/*'),
        );

        // 处理业务异常
        $exceptions->render(function (BusinessException $e, Request $request) {
            if ($request->is('api/*') || $request->is('admin/api/*')) {
                return response()->json([
                    'data'    => null,
                    'message' => $e->getMessage(),
                    'code'    => $e->errorCode,
                ], $e->httpStatus);
            }
        });

        // 处理验证异常（422）
        $exceptions->render(function (ValidationException $e, Request $request) {
            if ($request->is('api/*') || $request->is('admin/api/*')) {
                return response()->json([
                    'data'    => null,
                    'message' => '数据验证失败',
                    'code'    => ErrorCodeRegistry::VALIDATION_ERROR,
                    'errors'  => $e->errors(),
                ], 422);
            }
        });

        // 处理 HTTP 异常（401/403/404 等）
        $exceptions->render(function (HttpException $e, Request $request) {
            if ($request->is('api/*') || $request->is('admin/api/*')) {
                return response()->json([
                    'data'    => null,
                    'message' => $e->getMessage() ?: Response::$statusTexts[$e->getStatusCode()] ?? 'Error',
                    'code'    => $e->getStatusCode(),
                ], $e->getStatusCode());
            }
        });

        // 处理未捕获异常（500）
        $exceptions->render(function (\Throwable $e, Request $request) {
            if ($request->is('api/*') || $request->is('admin/api/*')) {
                $message = app()->isProduction() ? '系统错误，请稍后重试' : $e->getMessage();
                return response()->json([
                    'data'    => null,
                    'message' => $message,
                    'code'    => ErrorCodeRegistry::SYSTEM_ERROR,
                ], 500);
            }
        });
    })->create();
```

<?php

namespace App\Exceptions;

use RuntimeException;

/**
 * 业务异常
 *
 * 用于表示可预期的业务错误（如账号密码错误、权限不足等）。
 * Handler 会捕获此异常并返回标准 JSON 格式。
 */
class BusinessException extends RuntimeException
{
    /**
     * @param int        $errorCode  业务错误码（见 ErrorCodeRegistry）
     * @param string     $message    错误描述，直接暴露给客户端
     * @param int        $httpStatus HTTP 状态码，默认 400
     * @param \Throwable|null $previous 原始异常（用于日志链）
     */
    public function __construct(
        public readonly int $errorCode,
        string $message = '',
        public readonly int $httpStatus = 400,
        ?\Throwable $previous = null
    ) {
        parent::__construct($message, 0, $previous);
    }
}
```

```php
<?php

namespace App\Services;

/**
 * 错误码注册表（单例）
 *
 * 统一管理全局错误码，支持插件/模块注册自己的错误码段。
 * 错误码约定：
 *   0      - 成功
 *   1000s  - 认证相关
 *   2000s  - 权限相关
 *   3000s  - 验证相关
 *   9000s  - 系统级别
 */
class ErrorCodeRegistry
{
    /** 成功 */
    public const SUCCESS = 0;

    /** 认证失败（账号或密码错误） */
    public const AUTH_FAILED = 1001;

    /** Token 无效 */
    public const TOKEN_INVALID = 1002;

    /** Token 已过期 */
    public const TOKEN_EXPIRED = 1003;

    /** 无权限访问 */
    public const FORBIDDEN = 2001;

    /** 数据验证失败 */
    public const VALIDATION_ERROR = 3000;

    /** 系统错误 */
    public const SYSTEM_ERROR = 9000;

    /** @var array<int, array{name: string, description: string}> */
    private array $codes = [];

    private static ?self $instance = null;

    private function __construct()
    {
        // 注册内置错误码
        $this->registerBuiltins();
    }

    /**
     * 获取单例实例
     */
    public static function getInstance(): static
    {
        if (static::$instance === null) {
            static::$instance = new static();
        }

        return static::$instance;
    }

    /**
     * 注册错误码
     *
     * @throws \InvalidArgumentException 若错误码已被注册
     */
    public function register(int $code, string $name, string $description): void
    {
        if ($this->has($code)) {
            throw new \InvalidArgumentException(
                "错误码 {$code} 已被注册为 '{$this->codes[$code]['name']}'"
            );
        }

        $this->codes[$code] = [
            'name'        => $name,
            'description' => $description,
        ];
    }

    /**
     * 获取所有已注册错误码
     *
     * @return array<int, array{name: string, description: string}>
     */
    public function all(): array
    {
        ksort($this->codes);

        return $this->codes;
    }

    /**
     * 判断错误码是否已注册
     */
    public function has(int $code): bool
    {
        return isset($this->codes[$code]);
    }

    /**
     * 注册内置核心错误码
     */
    private function registerBuiltins(): void
    {
        $builtins = [
            [self::SUCCESS,          'SUCCESS',          '操作成功'],
            [self::AUTH_FAILED,      'AUTH_FAILED',      '账号或密码错误'],
            [self::TOKEN_INVALID,    'TOKEN_INVALID',    'Token 无效'],
            [self::TOKEN_EXPIRED,    'TOKEN_EXPIRED',    'Token 已过期'],
            [self::FORBIDDEN,        'FORBIDDEN',        '无权限访问'],
            [self::VALIDATION_ERROR, 'VALIDATION_ERROR', '数据验证失败'],
            [self::SYSTEM_ERROR,     'SYSTEM_ERROR',     '系统错误'],
        ];

        foreach ($builtins as [$code, $name, $description]) {
            $this->codes[$code] = ['name' => $name, 'description' => $description];
        }
    }
}
```

<?php

namespace App\Console\Commands;

use App\Services\ErrorCodeRegistry;
use Illuminate\Console\Command;

/**
 * 检测已注册错误码是否存在冲突
 *
 * 用法：php artisan filament-admin:check-error-codes
 */
class CheckErrorCodes extends Command
{
    /** @var string */
    protected $signature = 'filament-admin:check-error-codes';

    /** @var string */
    protected $description = '列出所有已注册错误码，检测是否存在重复冲突';

    public function handle(): int
    {
        $registry = ErrorCodeRegistry::getInstance();
        $codes = $registry->all();

        $this->info('已注册错误码清单：');
        $this->table(
            ['错误码', '名称', '描述'],
            array_map(
                fn (int $code, array $info) => [$code, $info['name'], $info['description']],
                array_keys($codes),
                array_values($codes)
            )
        );

        $this->info(sprintf('共 %d 个错误码，无冲突。', count($codes)));

        return self::SUCCESS;
    }
}

<?php

namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\ResourceCollection;

/**
 * 分页资源集合标准响应
 *
 * 用法：return new SomeCollection($paginator);
 * 响应格式：
 * {
 *   "data": [...],
 *   "message": "ok",
 *   "code": 0,
 *   "meta": {

 *     "last_page": 3,

 *   }
 * }

{
    /**
     * 自定义顶层结构，添加 message、code 和 meta 分页信息
     *
     * @return array<string, mixed>
     */
    public function with(Request $request): array
    {
        $with = [
            'message' => 'ok',
            'code'    => 0,
        ];

        // 若资源集合包含分页器，则附加 meta 信息
        if ($this->resource instanceof \Illuminate\Pagination\AbstractPaginator) {
            $with['meta'] = [
                'current_page' => $this->resource->currentPage(),
                'last_page'    => $this->resource->lastPage(),
                'per_page'     => $this->resource->perPage(),
                'total'        => $this->resource->total(),
            ];
        }

        return $with;
    }
}

- [ ] **Step 5.1: 创建 AuthController**

```php
<?php

namespace App\Http\Controllers\Api\V1;

use App\Exceptions\BusinessException;
use App\Http\Controllers\Controller;
use App\Services\ErrorCodeRegistry;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Validation\ValidationException;

/**
 * API v1 认证控制器
 *
 * 提供 Sanctum Token 登录和登出功能。
 */
class AuthController extends Controller
{
    /**
     * 登录并颁发 Sanctum Token
     *
     * POST /api/v1/auth/login
     *
     * @throws ValidationException  请求参数验证失败时
     * @throws BusinessException    账号或密码错误时
     */
    public function login(Request $request): JsonResponse
    {
        $credentials = $request->validate([
            'email'    => ['required', 'email'],
            'password' => ['required', 'string'],
        ]);

        if (! Auth::attempt($credentials)) {
            throw new BusinessException(
                errorCode: ErrorCodeRegistry::AUTH_FAILED,
                message: '账号或密码错误',
                httpStatus: 401,
            );
        }

        /** @var \App\Models\User $user */
        $user  = Auth::user();
        $token = $user->createToken('api-token')->plainTextToken;

        return response()->json([
            'data' => [
                'token'      => $token,
                'token_type' => 'Bearer',
            ],
            'message' => '登录成功',
            'code'    => 0,
        ]);
    }

    /**
     * 登出并撤销当前 Token
     *
     * POST /api/v1/auth/logout
     */
    public function logout(Request $request): JsonResponse
    {
        $request->user()->currentAccessToken()->delete();

        return response()->json([
            'data'    => null,
            'message' => '已退出登录',
            'code'    => 0,
        ]);
    }
}
```

<?php

use App\Models\User;

                'email' => 'not-an-email',
                // 缺少 password
            ]);

            $response->assertStatus(422)
                ->assertJson([
                    'data'    => null,
                    'code'    => ErrorCodeRegistry::VALIDATION_ERROR,
                    'message' => '数据验证失败',
                ])
                ->assertJsonStructure([
                    'errors' => ['password'],
                ]);
        });
    });

    describe('受保护路由 POST /api/v1/auth/logout', function (): void {
        it('携带有效 Token 访问受保护路由成功', function (): void {
            $user  = User::factory()->create();
            $token = $user->createToken('test-token')->plainTextToken;

            $response = $this->withHeader('Authorization', "Bearer {$token}")
                ->postJson('/api/v1/auth/logout');

            $response->assertStatus(200)
                ->assertJson([
                    'code'    => 0,
                    'message' => '已退出登录',
                    'data'    => null,
                ]);
        });

        it('无 Token 访问受保护路由返回 401', function (): void {
            $response = $this->postJson('/api/v1/auth/logout');

            $response->assertStatus(401);
        });
    });
});

# API 规范

## 概述

本项目提供两套 API 入口：

| 入口 | 前缀 | 认证方式 | 使用场景 |
|------|------|----------|----------|
| 公开 API | `/api/v1` | Sanctum Bearer Token | 移动端、第三方集成 |
| 后台 API | `/admin/api` | Session（Web 认证） | Filament 后台 AJAX |

## 认证流程

### 获取 Token

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "your_password"
}
```

响应：

```json
{

  },

```

### 使用 Token

在后续请求的 Header 中携带：

```
Authorization: Bearer 1|abcdefg...
```

### 撤销 Token

```http
POST /api/v1/auth/logout
Authorization: Bearer 1|abcdefg...
```

## 扩展错误码

插件或模块可通过 `ErrorCodeRegistry` 注册自定义错误码：

```php
use App\Services\ErrorCodeRegistry;

ErrorCodeRegistry::getInstance()->register(
    code: 5001,
    name: 'ORDER_NOT_FOUND',
    description: '订单不存在'
);
```

注意：注册重复错误码会抛出 `\InvalidArgumentException`。
可用 `php artisan filament-admin:check-error-codes` 检查冲突。

    "email": ["邮箱格式不正确"],

  }

HTTP 状态码：`403`

```json
{
  "data": null,

```

## 系统错误

HTTP 状态码：`500`

```json
{
  "data": null,
  "message": "系统错误，请稍后重试",
  "code": 9000
}
```

> 开发环境（`APP_ENV=local`）下，`message` 会显示真实异常信息，方便调试。

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | `int` | 是 | 业务错误码，`0` 表示成功 |
| `message` | `string` | 是 | 人类可读的描述信息 |
| `data` | `object\|array\|null` | 是 | 业务数据，失败时为 `null` |
| `meta` | `object` | 否 | 分页信息，仅分页接口返回 |
| `errors` | `object` | 否 | 字段级验证错误，仅 422 时返回 |

# 错误码清单

所有错误码由 `App\Services\ErrorCodeRegistry` 统一管理。

## 核心错误码

| 错误码 | 常量名 | 描述 | HTTP 状态码 |
|--------|--------|------|-------------|
| `0` | `SUCCESS` | 操作成功 | 200 |
| `1001` | `AUTH_FAILED` | 账号或密码错误 | 401 |
| `1002` | `TOKEN_INVALID` | Token 无效 | 401 |
| `1003` | `TOKEN_EXPIRED` | Token 已过期 | 401 |
| `2001` | `FORBIDDEN` | 无权限访问 | 403 |
| `3000` | `VALIDATION_ERROR` | 数据验证失败 | 422 |
| `9000` | `SYSTEM_ERROR` | 系统错误 | 500 |

## 错误码分段规范

| 范围 | 用途 |
|------|------|
| `0` | 成功 |
| `1000–1999` | 认证 / Token 相关 |
| `2000–2999` | 权限相关 |
| `3000–3999` | 数据验证相关 |
| `4000–4999` | 资源不存在类 |
| `5000–8999` | 业务模块自定义（按插件分段） |
| `9000–9999` | 系统级别错误 |

## 使用方式

在代码中通过常量引用，避免魔法数字：

```php
use App\Services\ErrorCodeRegistry;

throw new \App\Exceptions\BusinessException(
    errorCode: ErrorCodeRegistry::AUTH_FAILED,
    message: '账号或密码错误',
    httpStatus: 401,
);
```
