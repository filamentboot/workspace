# API 规范 实现计划

> 修订记录：2026-05-29 根据代码审查问题清单修复 8 项问题（认证对象已确认：C 端 web guard + User 模型 + Sanctum）。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现统一的 API 响应规范，包含 Sanctum Token 认证、统一 JSON 响应格式、BusinessException 异常类和 ErrorCodeRegistry 错误码注册机制。

**Architecture:** 所有 API 响应通过 `bootstrap/app.php` 的 `withExceptions` 统一格式化。BusinessException 携带错误码，异常处理捕获后输出标准格式。ErrorCodeRegistry 单例管理全局错误码，支持插件注册自己的错误码段。

**Tech Stack:** Laravel 13 + PHP 8.3、laravel/sanctum、Pest 4

## 前置依赖与认证对象说明

- **本域 API 服务对象为 C 端业务用户（`App\Models\User`），与后台 AdminUser（admin guard）完全隔离。** 后台管理员通过 Filament 内置 session 登录 `/admin/*`，不在本域范围内。
- 业务 API 走 `web` guard 校验账号密码，颁发 Sanctum Personal Access Token；后续请求通过 `auth:sanctum` middleware 验证 Token 对应的 `User`。
- Laravel 11+ 默认未发布 `routes/api.php`，需先执行 `php artisan install:api`（见 Task 0）。

use App\Http\Controllers\Api\V1\AuthController;

/**
 * API v1 路由组
 *
 * 服务对象：C 端业务用户（App\Models\User）
 * 认证方式：Sanctum Personal Access Token（auth:sanctum 中间件）

        Route::post('login', [AuthController::class, 'login'])->name('login');
    });

    // 需要 Token 认证的路由
    Route::middleware('auth:sanctum')->group(function (): void {
        Route::post('auth/logout', [AuthController::class, 'logout'])->name('auth.logout');
    });
});

- [ ] **Step 1.3: 修改 bootstrap/app.php，注册 admin-api 路由组和统一异常处理**

```php
<?php

use App\Enums\ApiErrorCode;
use App\Exceptions\BusinessException;
use Illuminate\Auth\AuthenticationException;
use Illuminate\Database\Eloquent\ModelNotFoundException;
use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;
use Illuminate\Http\Exceptions\ThrottleRequestsException;
use Illuminate\Http\Request;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpKernel\Exception\HttpException;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
        then: function (): void {
            // 注册 admin-api 路由，前缀 /admin/api
            \Illuminate\Support\Facades\Route::middleware('web')
                ->prefix('admin/api')
                ->group(base_path('routes/admin-api.php'));
        },
    )
    ->withMiddleware(function (Middleware $middleware): void {
        //
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        // 对所有 /api/* 和 /admin/api/* 请求返回 JSON
        $exceptions->shouldRenderJsonWhen(
            fn (Request $request) => $request->is('api/*') || $request->is('admin/api/*'),
        );

        $isApiRequest = fn (Request $request): bool => $request->is('api/*') || $request->is('admin/api/*');

        // 业务异常
        $exceptions->render(function (BusinessException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            return response()->json([
                'code'    => $e->errorCode,
                'message' => $e->getMessage(),
                'data'    => null,
            ], $e->httpStatus);
        });

        // 参数校验失败（422）
        $exceptions->render(function (ValidationException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            return response()->json([
                'code'    => ApiErrorCode::ValidationFailed->value,
                'message' => '参数校验失败',
                'data'    => null,
                'errors'  => $e->errors(),
            ], 422);
        });

        // 未认证 / Token 无效（401）
        $exceptions->render(function (AuthenticationException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            return response()->json([
                'code'    => ApiErrorCode::Unauthenticated->value,
                'message' => '未登录或登录已过期',
                'data'    => null,
            ], 401);
        });

        // 资源不存在（404）
        $exceptions->render(function (ModelNotFoundException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            return response()->json([
                'code'    => ApiErrorCode::ResourceNotFound->value,
                'message' => '资源不存在',
                'data'    => null,
            ], 404);
        });

        // 限流（429）
        $exceptions->render(function (ThrottleRequestsException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            return response()->json([
                'code'    => ApiErrorCode::TooManyRequests->value,
                'message' => '请求过于频繁，请稍后再试',
                'data'    => null,
            ], 429);
        });

        // 通用 HTTP 异常（403/405 等）
        $exceptions->render(function (HttpException $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            $code = match ($e->getStatusCode()) {
                403     => ApiErrorCode::Forbidden->value,
                404     => ApiErrorCode::ResourceNotFound->value,
                default => ApiErrorCode::ServerError->value,
            };

            return response()->json([
                'code'    => $code,
                'message' => $e->getMessage() ?: '请求异常',
                'data'    => null,
            ], $e->getStatusCode());
        });

        // 未捕获异常（500）
        $exceptions->render(function (\Throwable $e, Request $request) use ($isApiRequest) {
            if (! $isApiRequest($request)) {
                return null;
            }

            $message = app()->isProduction() ? '系统错误，请稍后重试' : $e->getMessage();

            return response()->json([
                'code'    => ApiErrorCode::ServerError->value,
                'message' => $message,
                'data'    => null,
            ], 500);
        });
    })->create();
```

> 异常处理位置：Laravel 11+ 已移除旧 `app/Exceptions/Handler.php`，所有 renderable 必须注册在 `bootstrap/app.php` 的 `->withExceptions()` 块中。

<?php

namespace App\Exceptions;

use App\Enums\ApiErrorCode;
use RuntimeException;

/**
 * 业务异常
 *
 * 用于表示可预期的业务错误（如账号密码错误、权限不足等）。
 * bootstrap/app.php 的 withExceptions 会捕获此异常并返回标准 JSON 格式。
 */
class BusinessException extends RuntimeException
{
    /**
     * @param int             $errorCode  业务错误码（见 ApiErrorCode 枚举）
     * @param string          $message    错误描述，直接暴露给客户端
     * @param int             $httpStatus HTTP 状态码，默认 400
     * @param \Throwable|null $previous   原始异常（用于日志链）
     */
    public function __construct(
        public readonly int $errorCode,
        string $message = '',
        public readonly int $httpStatus = 400,
        ?\Throwable $previous = null,
    ) {
        parent::__construct($message, 0, $previous);
    }

    /**
     * 通过 ApiErrorCode 枚举构造，避免魔法数字
     */
    public static function fromEnum(ApiErrorCode $code, ?string $message = null, int $httpStatus = 400): self
    {
        return new self(
            errorCode: $code->value,
            message: $message ?? $code->defaultMessage(),
            httpStatus: $httpStatus,
        );
    }
}
```

```php
<?php

namespace App\Enums;

/**
 * API 错误码注册表（PHP 8.1 enum）
 *
 * 错误码分段约定：
 *   0      - 成功
 *   1000s  - 认证相关
 *   2000s  - 权限相关
 *   3000s  - 参数校验
 *   4000s  - 资源不存在
 *   5000–8999 - 业务模块自定义（按插件分段）
 *   9000s  - 系统级别 / 限流
 */
enum ApiErrorCode: int
{
    case Success           = 0;

    // 认证（1000s）
    case AuthFailed        = 1001;
    case TokenInvalid      = 1002;
    case TokenExpired      = 1003;
    case Unauthenticated   = 1004;

    // 权限（2000s）
    case Forbidden         = 2001;

    // 参数校验（3000s）
    case ValidationFailed  = 3000;

    // 资源（4000s）
    case ResourceNotFound  = 4004;

    // 系统（9000s）
    case TooManyRequests   = 9001;
    case ServerError       = 9000;

    /**
     * 默认中文描述
     */
    public function defaultMessage(): string
    {
        return match ($this) {
            self::Success          => '操作成功',
            self::AuthFailed       => '账号或密码错误',
            self::TokenInvalid     => 'Token 无效',
            self::TokenExpired     => 'Token 已过期',
            self::Unauthenticated  => '未登录或登录已过期',
            self::Forbidden        => '无权限访问',
            self::ValidationFailed => '参数校验失败',
            self::ResourceNotFound => '资源不存在',
            self::TooManyRequests  => '请求过于频繁，请稍后再试',
            self::ServerError      => '系统错误，请稍后重试',
        };
    }
}
```

- [ ] **Step 3.2: 创建 ErrorCodeRegistry（聚合 enum + 插件注册）**

```php
<?php

namespace App\Services;

use App\Enums\ApiErrorCode;

/**
 * 错误码注册表（单例）
 *
 * 内置错误码来源于 ApiErrorCode 枚举；
 * 插件 / 模块可通过 register() 注册自定义错误码段（5000–8999）。
 */
class ErrorCodeRegistry
{
    /** @var array<int, array{name: string, description: string}> */
    private array $codes = [];

    private static ?self $instance = null;

    private function __construct()
    {
        $this->registerBuiltins();
    }

    public static function getInstance(): self
    {
        return self::$instance ??= new self();
    }

    /**
     * 注册自定义错误码
     *
     * @throws \InvalidArgumentException 若错误码已被注册
     */
    public function register(int $code, string $name, string $description): void
    {
        if ($this->has($code)) {
            throw new \InvalidArgumentException(
                "错误码 {$code} 已被注册为 '{$this->codes[$code]['name']}'",
            );
        }

        $this->codes[$code] = [
            'name'        => $name,
            'description' => $description,
        ];
    }

    /**
     * @return array<int, array{name: string, description: string}>
     */
    public function all(): array
    {
        ksort($this->codes);

        return $this->codes;
    }

    public function has(int $code): bool
    {
        return isset($this->codes[$code]);
    }

    /**
     * 注册 ApiErrorCode 枚举中的所有内置错误码
     */
    private function registerBuiltins(): void
    {
        foreach (ApiErrorCode::cases() as $case) {
            $this->codes[$case->value] = [
                'name'        => $case->name,
                'description' => $case->defaultMessage(),
            ];
        }
    }
}
```

namespace App\Console\Commands;

class BaseApiCollection extends ResourceCollection
{
    /**
     * @return array<string, mixed>
     */
    public function with(Request $request): array
    {
        $with = [
            'code'    => ApiErrorCode::Success->value,
            'message' => 'ok',
        ];

        if ($this->resource instanceof \Illuminate\Pagination\AbstractPaginator) {
            $with['meta'] = [
                'current_page' => $this->resource->currentPage(),
                'last_page'    => $this->resource->lastPage(),
                'per_page'     => $this->resource->perPage(),
                'total'        => $this->resource->total(),
            ];
        }

        return $with;
    }
}
```

## Task 5: AuthController（C 端 web guard + Sanctum）

**Files:**
- 创建: `app/Http/Controllers/Api/V1/AuthController.php`

- [ ] **Step 5.1: 创建 AuthController**

> **重要：** 本控制器服务对象为 C 端业务用户（`App\Models\User`），认证走 `web` guard（Laravel 默认 `users` 表）。**不要使用 `AdminUser` 或 `admin` guard** —— 后台管理员另有独立 session 登录入口。

```php
<?php

namespace App\Http\Controllers\Api\V1;

use App\Enums\ApiErrorCode;
use App\Exceptions\BusinessException;
use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

/**
 * API v1 认证控制器（C 端用户）
 *
 * 服务对象：App\Models\User（web guard）
 * 认证方式：账号密码校验通过后颁发 Sanctum Personal Access Token。
 */
class AuthController extends Controller
{
    /**
     * 登录并颁发 Sanctum Token
     *
     * POST /api/v1/auth/login
     */
    public function login(Request $request): JsonResponse
    {
        $credentials = $request->validate([
            'email'    => ['required', 'email'],
            'password' => ['required', 'string'],
        ]);

        // 显式使用 web guard 校验 C 端 User，避免与后台 admin guard 混淆
        if (! Auth::guard('web')->attempt($credentials)) {
            throw BusinessException::fromEnum(
                ApiErrorCode::AuthFailed,
                httpStatus: 401,
            );
        }

        /** @var User $user */
        $user  = Auth::guard('web')->user();
        $token = $user->createToken('api-token')->plainTextToken;

        return response()->json([
            'code'    => ApiErrorCode::Success->value,
            'message' => '登录成功',
            'data'    => [
                'token'      => $token,
                'token_type' => 'Bearer',
            ],
        ]);
    }

    /**
     * 登出并撤销当前 Token
     *
     * POST /api/v1/auth/logout
     */
    public function logout(Request $request): JsonResponse
    {
        /** @var \Laravel\Sanctum\PersonalAccessToken|null $token */
        $token = $request->user()?->currentAccessToken();
        $token?->delete();

        return response()->json([
            'code'    => ApiErrorCode::Success->value,
            'message' => '已退出登录',
            'data'    => null,
        ]);
    }
}
```

# API 规范

## 概述

本项目提供两套相互隔离的 API 入口：

| 入口 | 前缀 | 服务对象 | 认证方式 | 使用场景 |

# API 响应格式参考

所有响应严格遵循 `{ code, message, data, meta?, errors? }` 结构。
`code` 为**业务错误码**（非 HTTP 状态码），`0` 表示成功；HTTP 状态码通过响应头表达。

## 成功响应

```json
{
  "code": 0,
  "message": "操作成功",
  "data": {}
}
```

## 分页响应

```json
{
  "code": 0,
  "message": "ok",
  "data": [],
  "meta": {
    "current_page": 1,
    "last_page": 3,
    "per_page": 15,
    "total": 45
  }
}
```

## 业务错误

HTTP 状态码：`400`（或其他 4xx，取决于错误类型）

```json
{
  "code": 1001,
  "message": "账号或密码错误",
  "data": null
}
```

## 参数校验失败

HTTP 状态码：`422`

```json
{
  "code": 3000,
  "message": "参数校验失败",
  "data": null,
  "errors": {
    "email": ["邮箱格式不正确"],
    "password": ["密码不能为空"]
  }
}
```

## 未认证 / Token 失效

HTTP 状态码：`401`

```json
{
  "code": 1004,
  "message": "未登录或登录已过期",
  "data": null
}
```

## 无权限

HTTP 状态码：`403`

```json
{
  "code": 2001,
  "message": "无权限访问",
  "data": null
}
```

## 资源不存在

HTTP 状态码：`404`

```json
{
  "code": 4004,
  "message": "资源不存在",
  "data": null
}
```

## 限流

HTTP 状态码：`429`

```json
{
  "code": 9001,
  "message": "请求过于频繁，请稍后再试",
  "data": null
}
```

## 系统错误

HTTP 状态码：`500`

```json
{
  "code": 9000,
  "message": "系统错误，请稍后重试",
  "data": null
}
```

> 开发环境（`APP_ENV=local`）下，`message` 会显示真实异常信息便于调试。

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | `int` | 是 | 业务错误码，`0` 表示成功（与 HTTP 状态码独立） |
| `message` | `string` | 是 | 人类可读描述 |
| `data` | `object\|array\|null` | 是 | 业务数据，失败时为 `null` |
| `meta` | `object` | 否 | 分页信息，仅分页接口返回 |
| `errors` | `object` | 否 | 字段级校验错误，仅 422 返回 |
```
