## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 匿名用户 → 密码重置请求 | 任意人可提交 email，需防枚举 + 限流滥发 |
| 重置 token → 设新密码 | token 须时效短、单次有效 |
| 命令行 → 日志清理 | 误删风险（保留天数过小） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-09 | Denial of Service | 密码重置邮件滥发 | mitigate | broker throttle=60s（config/auth.php 已配），用 Laravel 默认限流（D-08） |
| T-07-10 | Information Disclosure | 重置接口用户枚举 | accept | Filament/Laravel 默认对存在与否返回一致状态；登录页已有防枚举（Login::throwFailureValidationException） |
| T-07-11 | Tampering | 过期/重放 token 设密码 | mitigate | broker expire=60min + 单次 token（Laravel 默认），不自定义削弱 |
| T-07-12 | Information Disclosure | 日志保留天数过小误删 | mitigate | retention<=0 视为永久保留不删；CleanLogsRetentionTest 覆盖 0 与覆盖值 |
