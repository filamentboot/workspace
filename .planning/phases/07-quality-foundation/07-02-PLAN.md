## 关键约束（来自 CONTEXT / ROADMAP / 现状核查）

- **现状：** MenuResource 第 83-93 行 `Radio::make('link_type')` 带 `->dehydrated(false)`（不写库）、`->default(fn ($record) => filled($record?->url) ? 'url' : 'route')`（每次从 url 推断）；menus 表无 link_type 列；Menu model 无 link_type @property / cast。
- **迁移命名：** 沿用包内迁移日期前缀风格（参考 `2026_06_02_000001_add_type_to_menus_table.php`），新文件用 `2026_06_11_000001_add_link_type_to_menus_table.php`。
- **link_type 取值：** `route` / `url`，与表单 Radio options 一致。列设 `string`，默认 `'route'`，置于 url/route_name 相关列附近（`after` 取一个稳定存在列，如 `source` 或 `type`，避免依赖不存在列名）。
- **回填默认值：** Radio defaultValue 改为：编辑既有记录时读 `$record->link_type`，为空时再回退按 url 推断（兼容历史无值数据）；新建时默认 'route'。
- Menu `$guarded = []`（全可填充），无需改 fillable，但需补 `@property string $link_type` 与（如需）casts；link_type 为简单字符串可不强制 cast，但要补 @property 以满足项目 PHPDoc 约定。
