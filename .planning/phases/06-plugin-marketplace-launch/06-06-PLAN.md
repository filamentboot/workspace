    marketplace.blade.php（第 74-76 行附近）：

    修改为：
    ```blade
    @php $docUrl = $entry['documentation_url'] ?? ''; @endphp
    @if (!empty($docUrl) && preg_match('#^https?://#i', $docUrl))
        <a href="{{ $docUrl }}" target="_blank" rel="noopener noreferrer"
    ```
    保持 </a> 和后续 @endif 不变，只收窄条件。

    现有第 44 行：
    ```blade
    $docUrl = $entry['documentation_url'] ?? null;
    ```

    ```blade
    @if ($docUrl)
        <a href="{{ $docUrl }}" target="_blank" rel="noopener noreferrer"
    ```
    修改 @if 条件为：
    ```blade
    @if ($docUrl && preg_match('#^https?://#i', $docUrl))
        <a href="{{ $docUrl }}" target="_blank" rel="noopener noreferrer"
    ```
    $docUrl 赋值行不变；只收窄 @if 条件。

    两处修改原则：不改动标签 class、target、rel 属性，不改动 @endif 位置，仅在 @if 条件中增加 scheme 白名单正则。
