<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 命令行参数（VERSION）→ 脚本内 git/gh 命令 | 未校验参数被拼入 push/tag 命令 |
| 本地脚本 → 外部包仓库（GitHub/Gitee） | SSH remote 推送写入外部仓库 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | release-package.sh TAG 参数注入 | mitigate | `${1:?}` 强制参数 + `set -u` 未定义变量即退出 + CHANGELOG `grep -q` 前置校验，非法版本无法走完流程 |
| T-04-RB | Tampering | release-rollback.sh 误删 | mitigate | 交互式 `read -p` y/N 确认，非 y 立即退出；删除命令 `|| true` 幂等不级联失败 |
| T-04-FAIL | Denial of Service | 任一步骤失败导致半成品发版 | mitigate | `set -euo pipefail` 任一步失败即非 0 退出（RELEASE-02 要求），不继续后续步骤 |
| T-04-PKG | Tampering | npm/pip/cargo installs | accept | 脚本运行时 `composer create-project`/`composer require` 安装的是本项目自身包，非引入新第三方依赖；无 slopcheck 适用对象 |
</threat_model>
