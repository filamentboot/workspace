    Steps 按顺序（中文 step name，参照包 CI 风格）：
    (1) checkout：`actions/checkout@v4`，`with.fetch-depth: 0`（D-36 / RESEARCH Pitfall：缺此项 subtree split 遗漏早期提交）。
    (2) 配置 Git 身份：`git config user.name "github-actions[bot]"` + `git config user.email "github-actions[bot]@users.noreply.github.com"`（Pitfall 2：CI 无默认 identity，否则 `git tag -a` 失败）。
    (3) 获取 Tag 名称：step `id: tag`，`echo "TAG=${GITHUB_REF#refs/tags/}" >> $GITHUB_OUTPUT`。
    (4) subtree split：先 `git branch -D "tmp/split-$TAG" 2>/dev/null || true`（Pitfall 4 防重跑分支冲突），再 `git subtree split --prefix=packages/filament-admin -b "tmp/split-$TAG"`（D-36）。
    (5) 配置包仓库认证：`git remote add package-github https://x-access-token:${{ secrets.PACKAGE_GITHUB_TOKEN }}@github.com/john-captain/filament-admin.git`（D-39 HTTPS 注入 PAT；Pitfall 3：默认 GITHUB_TOKEN 无法 push 外部仓库）。
    (6) 推送 main（force）：`git push package-github "tmp/split-$TAG":main --force`（D-37）。
    (7) 推送 tag 到包仓库：`SPLIT_SHA=$(git rev-parse "tmp/split-$TAG")` → `git tag -a "$TAG" "$SPLIT_SHA" -m "$TAG 发布"` → `git push package-github "$TAG"`。
    (8) 提取 CHANGELOG 版本说明：使用版本号过滤版 awk（RESEARCH Pattern 3 / Pitfall 1，禁用位置驱动版本，否则会提取 `[Unreleased]`）：`VER="${TAG#v}"`，awk 在遇到 `/^## \[/` 时：若已 found 则 exit，否则 `index($0,"["ver"]")` 命中才置 found=1，next；found 时打印行 → 输出到 `/tmp/release-notes.md`。提取后 `cat /tmp/release-notes.md` 预览。
    (9) 创建 GitHub Release：`env.GH_TOKEN: ${{ secrets.PACKAGE_GITHUB_TOKEN }}`（创建在 john-captain/filament-admin 上需该仓库的 token，非默认 GITHUB_TOKEN）；`gh release create "$TAG" --repo john-captain/filament-admin --title "$TAG" --notes-file /tmp/release-notes.md`（D-38）。
    所有引用 TAG 的 step 用 `TAG=${{ steps.tag.outputs.TAG }}` 取值。禁止在 yaml run 块外内联硬编码任何 secret 明文。
