| Boundary | Description |
|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | CosSettings.secret_key 存储 | mitigate | Settings `encrypted()` 声明 + SettingsMigration `addEncrypted()`，凭证 AES-256-CBC 加密存于 settings 表（Task 2 测试断言加密字段声明） |
| T-08-02 | Denial of Service | CosServiceProvider::boot() 首次迁移前读 settings/plugins | mitigate | `try/catch (\Throwable)` 包裹 Settings 与 plugins 表读取，表缺失时静默跳过不阻断应用启动（Task 3 测试断言不抛异常） |
| T-08-10 | Elevation of Privilege | 插件禁用后磁盘仍可被使用 | mitigate | boot() 注入磁盘前检查 plugins.is_enabled，禁用插件不注入 cos 磁盘配置（Task 3 测试断言未启用时磁盘未注入，D-08-10） |
| T-08-04 | Spoofing/Tampering | extra.filament-admin 契约字段被 plugin:scan 信任 | accept | source=official_listed 由本项目自发布；plugin:scan 仅信任 official_trusted/official_listed |
| T-08-SC | Tampering | composer require overtrue/laravel-filesystem-cos | accept | RESEARCH Package Legitimacy Audit 已通过 Packagist 直接验证（v4.0.0 明确支持 Laravel 13，github.com/overtrue/laravel-filesystem-cos），slopcheck [SLOP] 为 npm 注册表误判；非 [ASSUMED]/[SUS]，无需阻断 checkpoint |
</threat_model>
