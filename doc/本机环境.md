## 二、PHP 配置

**PHP-FPM Socket：** `/run/php/php8.3-fpm.sock`  
**FPM 运行用户：** `john:john`

已启用扩展：`bcmath` · `curl` · `gd` · `mbstring` · `pdo_mysql` · `redis` · `zip` · `opcache`

**Nginx PHP 代理 Snippet：** `/etc/nginx/snippets/php83.conf`

```nginx
location ~ \.php$ {
    fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
    fastcgi_index index.php;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include /etc/nginx/fastcgi_params;
    fastcgi_buffer_size 128k;
    fastcgi_buffers 256 16k;
    fastcgi_read_timeout 300;
}
```

## 七、注意事项

### 系统代理

系统全局设置了 HTTP 代理（`127.0.0.1:10808`）。运行 `composer require` / `npm install` 时如遇超时，先执行：

```bash
unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy
```

### Windows 浏览器访问 WSL 站点

需在 **Windows** 的 `C:\Windows\System32\drivers\etc\hosts` 中添加对应记录：

```
127.0.0.1 filamentadmin.local
127.0.0.1 adsl.local
```

### PHP-FPM 重启

```bash
sudo systemctl restart php8.3-fpm
sudo systemctl status php8.3-fpm
```
